МОЯ КУХНЯ — файлы для превращения сайта в устанавливаемое приложение

1. Сделай резервную копию своей рабочей папки «моя кухня».
2. Распакуй эти файлы и скопируй в ту же папку, где находится index.html,
   то есть в папку «моя кухня», рядом с папкой images.
   Внутри этой папки должны лежать:
     index.html
     manifest.json
     service-worker.js
     icon-192.png
     icon-512.png
     images\

3. В index.html добавь в раздел <head> две строки ниже.
   Их можно поставить после <title>Моя кухня</title>:

   <link rel="manifest" href="./manifest.json">
   <meta name="theme-color" content="#54745b">

4. В самом низу index.html найди закрывающий тег </body>.
   ПРЯМО ПЕРЕД ним вставь ещё один отдельный блок <script>:

   <script>
   if ("serviceWorker" in navigator) {
     window.addEventListener("load", () => {
       navigator.serviceWorker.register("./service-worker.js")
         .catch(error => console.warn("Не удалось включить офлайн-режим:", error));
     });
   }
   </script>

   Важно: не вставляй этот код внутрь уже существующего <script>.
   Он должен быть отдельным блоком перед </body>.

5. Сохрани index.html (Ctrl+S) и открой страницу через Live Server.
   Для разработки localhost/127.0.0.1 подходит. Просто открыть index.html
   двойным щелчком недостаточно для service worker.

6. В Chrome или Edge проверь меню браузера: обычно там появляется пункт
   «Установить Моя кухня» или значок установки в адресной строке.
   Доступность пункта зависит от версии браузера и успешной загрузки файлов.

ОФЛАЙН:
- Страница и иконки будут сохранены для офлайн-запуска.
- Файлы с изображениями сохраняются в кэш по мере загрузки при подключении к сети.
  Чтобы больше фотографий были доступны без интернета, пока сеть есть, открой
  категории и дай фотографиям загрузиться.
- Поиск изображений в Wikimedia требует интернет, если конкретное изображение
  ещё не закэшировано.

ВАЖНО:
- Не удаляй и не переименовывай папку images.
- Эти файлы не заменяют index.html и не меняют рецепты или CSS.
- Сейчас адрес 127.0.0.1 доступен только на этом компьютере. Для установки
  приложения на телефон понадобится опубликовать папку на HTTPS-сайте.
